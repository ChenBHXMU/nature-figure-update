根据我的日常使用，更新了nature-figure skill。 更新主要在三处：

1. 不再是“先画大图、最后再缩小” 以前是画个很大的图，然后缩到杂志尺寸，缩完后字就变小、容易看不清。现在改成一开始就按杂志要求的实际大小来画（单栏约 9 厘米、双栏约 18 厘米），字号直接定成对应大小（坐标轴 7 号、刻度 6–7 号），一步到位，不用再后期缩放。

2. 默认导出格式改了 以前默认给的是 SVG/PDF/TIFF 这种矢量图；现在默认给PNG 高清图（300–600 dpi）。只有杂志特别要求矢量图时才额外给 SVG，特别要求才给 PDF。

3. 配色变得更“规矩”了 以前为了区分不同组，喜欢用很鲜艳、花花绿绿的颜色。现在改用柔和低饱和的色系，同一类的东西用同一族的深浅色，整页看起来干净统一。而且绿和红只留给“升高/降低”这种有方向的意思用，不会拿来随便标两组，读者一看绿色就懂是涨、红色是跌。
